## Resolved inventory and validation

The [baseline inventory run](https://github.com/UNICEFECAR/parenting-app-bebbo-mobile/actions/runs/43523394586) resolves all ten release runtime classpaths and 42 project buildscript classpaths, rejecting unresolved graph entries. Its union contains **926 Maven package/version pairs**, of which **266** distinct pairs occur in app runtime graphs. OSV's exact-version query reports **66 affected pairs** across all graphs; only Gson 2.8.8 and Guava 33.5.0-android occur in app runtime graphs. Multiple advisory IDs can apply to a pair; these are not counts of exploitable app bugs.

The [baseline evidence](evidence/native-maven-audit-before.json) records every matched package/version, scope and advisory severity, with the inventory digest. The exact QA workflow is retained at its immutable [controller commit](https://github.com/UNICEFECAR/parenting-app-bebbo-mobile/blob/297251e51995b807651af3fa82f12ab911d9423b/.github/workflows/native-build-audit.yml). It is a build driver, not an application feature.

The [patched-runtime run](https://github.com/UNICEFECAR/parenting-app-bebbo-mobile/actions/runs/43525862764) checks out `7760562e`, asserts the patched selected versions in every release graph, passed resolution for all ten variants: all 266 distinct runtime package/version pairs return no current OSV matches, as recorded in the [post-fix evidence](evidence/native-maven-runtime-after.json). Its later compile-driver step used a non-existent mergeExtDex task for these minified releases; that is a validation-script failure, not a successful compile. The corrected [run 43526704454](https://github.com/UNICEFECAR/parenting-app-bebbo-mobile/actions/runs/43526704454) compiles Java for all ten variants and attempts a representative full Bebbo release, including R8/dex. Consult the final follow-up report and run result; starting this run is not a successful build result.

The [Ruby compatibility run](https://github.com/UNICEFECAR/parenting-app-bebbo-mobile/actions/runs/43523202286) passed. Its [hash/change summary](evidence/ruby-update-validation.json) verifies the native-input comparison. Re-querying all 45 selected gems removes all three concurrent-ruby advisories; Active Support below remains.
