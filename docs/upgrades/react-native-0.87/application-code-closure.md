## Acceptance that cannot be declared closed from this repository

**Country-specific ATS restrictions:** the current branch and original
`RNSDKUpgrade` branch do not track the required `env/` configuration. Public source
origins are inventoried, but do not establish production API/media/CDN origins,
redirects or device trust. Supply the production API and media/CDN origins for each
flavour (scheme and hostname only; no credentials), or provide the deployed
configuration's origin inventory. Arbitrary-load exceptions cannot safely be
removed by assuming fake CI hosts or static content links are the whole runtime
network surface.

**Production services and device acceptance:** live analytics/Crashlytics, real
Drive authorisation/restore, signed-store behaviour, physical VoiceOver/TalkBack
and representative RTL/large-text/older-device acceptance still require the
relevant service/test session and devices. Source, unit, bundle and unsigned CI
checks do not establish those scenarios. These remain acceptance dependencies;
they are not silently marked compliant or represented as unobserved code bugs.
